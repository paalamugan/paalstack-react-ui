# Icon Library

A comprehensive collection of **31 icon packs** with thousands of icons powered by [react-icons](https://www.npmjs.com/package/react-icons). Choose from popular icon libraries like Radix, Lucide, Material Design, Heroicons, Font Awesome, and many more.

---

## 📦 Installation

```bash
npm install @paalstack/react-icons
```

---

## 🚀 Quick Start

Import icons from any pack and use them as React components:

```tsx
// Import from different icon packs
import { Fa6User } from '@paalstack/react-icons/fa6'; // Font Awesome 6

import { HiHeart } from '@paalstack/react-icons/hi2'; // Heroicons 2
import { LuStar } from '@paalstack/react-icons/lu'; // Lucide Icons
import { MdFavorite } from '@paalstack/react-icons/md'; // Material Design
import { RxHome } from '@paalstack/react-icons/rx'; // Radix Icons

function MyComponent() {
  return (
    <div>
      <RxHome />
      <LuStar />
      <MdFavorite />
    </div>
  );
}
```

### Using IconContext Provider

Apply default props to all icons within a context:

<IconContext.Provider value={{ color: 'blue', size: '1.5em', className: 'icon-group' }}>
  <div
    style={{
      display: 'flex',
      gap: '1rem',
      padding: '1rem',
      background: '#f8f9fa',
      borderRadius: '8px',
      marginBottom: '1rem',
    }}
  >
    <RxHome />
    <RxRocket />
    <RxGear />
    <RxPerson />
  </div>
</IconContext.Provider>

```tsx
import { IconContext } from '@paalstack/react-icons';
import { RxGear, RxHome, RxPerson, RxRocket } from '@paalstack/react-icons/rx';

function MyComponent() {
  return (
    <IconContext.Provider value={{ color: 'blue', size: '1.5em', className: 'icon-group' }}>
      <div>
        <RxHome />
        <RxRocket />
        <RxGear />
        <RxPerson />
      </div>
    </IconContext.Provider>
  );
}
```

// Context provides default red color

## ⚙️ Available Props

All icons accept the following props:

```typescript
interface IconBaseProps {
  color?: string; // Icon color (any CSS color)
  size?: string | number; // Icon size (in pixels or CSS value)
  className?: string; // CSS classes
  style?: React.CSSProperties; // Inline styles
  attr?: React.SVGAttributes<SVGElement>; // SVG attributes
  title?: string; // Accessibility title
}
```

### Individual Icon Props

```tsx
<RxHome size={32} color="blue" className="my-icon" title="Home Icon" style={{ cursor: 'pointer' }} />
```

### Using IconContext (Global Props)

Set default props for multiple icons using `IconContext.Provider`:

```tsx
import { IconContext } from '@paalstack/react-icons';

// All icons inherit these props
<IconContext.Provider
  value={{
    color: 'blue',
    size: '1.5em',
    className: 'global-icon-class',
  }}
>
  <RxHome /> {/* blue, 1.5em */}
  <RxGear /> {/* blue, 1.5em */}
  <RxPerson color="red" /> {/* red, 1.5em - individual prop overrides context */}
</IconContext.Provider>;
```

**Priority:** Individual props > Context props > Default values

## 💡 Best Practices

<div style={{ background: '#d4edda', padding: '1rem', borderRadius: '8px', marginBottom: '1rem' }}>

✓ **Tree-shaking**: Import only the icons you need to keep bundle size small

✓ **Consistency**: Stick to one or two icon packs for a consistent design

✓ **Accessibility**: Use the `title` prop for screen readers

✓ **Performance**: Use Tailwind CSS classes for better performance

✓ **Sizing**: Prefer className over inline styles for better caching

✓ **Context**: Use `IconContext` for consistent styling across icon groups
