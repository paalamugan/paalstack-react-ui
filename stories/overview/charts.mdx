# Charts & Data Visualization

Beautiful, customizable charts built with [Recharts](https://recharts.github.io/). Our chart components are designed to work seamlessly with your design system, supporting theming, accessibility, and full customization.

## Overview

All chart components are built on top of Recharts with custom styling and theming support. They integrate perfectly with our component library and support both light and dark themes out of the box.

### Key Features

- 🎨 **Themeable** - Built-in support for CSS variables and custom theming
- ♿ **Accessible** - Full keyboard navigation and screen reader support
- 📱 **Responsive** - Adapts to different screen sizes automatically
- 🎯 **Customizable** - Extensive customization options for tooltips, legends, and more
- 🌙 **Dark Mode** - Automatic dark mode support with theme switching
- 📊 **Multiple Chart Types** - Area, Bar, Line, Pie, Radar, and Radial charts

## Installation

The chart components are part of the `@paalstack/react-ui` package. We use **Recharts v3**, which includes improved performance, better accessibility defaults, and enhanced TypeScript support.

```bash
pnpm add @paalstack/react-ui recharts
```

**Note:** Recharts v3 requires React 16.8+, TypeScript 5.x+, and Node.js v18+.

## Basic Usage

```tsx
import { ChartContainer, ChartTooltip, ChartTooltipContent } from '@paalstack/react-ui';
import { Area, AreaChart, CartesianGrid, XAxis } from 'recharts';

const chartData = [
  { month: 'January', value: 186 },
  { month: 'February', value: 305 },
  { month: 'March', value: 237 },
];

const chartConfig = {
  value: {
    label: 'Value',
    color: 'var(--chart-1)',
  },
};

export function MyChart() {
  return (
    <ChartContainer config={chartConfig} className="w-full" height={250} initialDimension={{ width: 320, height: 200 }}>
      <AreaChart data={chartData}>
        <CartesianGrid vertical={false} />
        <XAxis dataKey="month" tickLine={false} axisLine={false} />
        <ChartTooltip content={<ChartTooltipContent />} />
        <Area dataKey="value" fill="var(--color-value)" stroke="var(--color-value)" />
      </AreaChart>
    </ChartContainer>
  );
}
```

**With TypeScript (Recommended):**

```tsx
import type { ChartConfig } from '@paalstack/react-ui';

import { ChartContainer, ChartTooltip, ChartTooltipContent } from '@paalstack/react-ui';
import { Area, AreaChart, CartesianGrid, XAxis } from 'recharts';

interface ChartData {
  month: string;
  value: number;
}

const chartData: ChartData[] = [
  { month: 'January', value: 186 },
  { month: 'February', value: 305 },
  { month: 'March', value: 237 },
];

const chartConfig = {
  value: {
    label: 'Value',
    color: 'var(--chart-1)',
  },
} satisfies ChartConfig;

export function MyChart() {
  return (
    <ChartContainer config={chartConfig} height={250} className="w-full">
      <AreaChart data={chartData} accessibilityLayer>
        <CartesianGrid vertical={false} />
        <XAxis dataKey="month" tickLine={false} axisLine={false} />
        <ChartTooltip content={<ChartTooltipContent />} />
        <Area dataKey="value" fill="var(--color-value)" stroke="var(--color-value)" />
      </AreaChart>
    </ChartContainer>
  );
}
```

## Chart Configuration

All charts use a `ChartConfig` object to define colors, labels, and icons:

```tsx
const chartConfig = {
  desktop: {
    label: 'Desktop',
    color: 'var(--chart-1)',
    icon: MonitorIcon,
  },
  mobile: {
    label: 'Mobile',
    color: 'var(--chart-2)',
    icon: SmartphoneIcon,
  },
} satisfies ChartConfig;
```

## Components

### ChartContainer

Wrapper component that provides context and responsive sizing for charts. Built on top of Recharts' `ResponsiveContainer` with enhanced props.

**Basic Usage:**

```tsx
<ChartContainer config={chartConfig} className="max-h-[250px] w-full">
  {/* Your Recharts components */}
</ChartContainer>
```

**With Enhanced Props (Recharts v3):**

```tsx
<ChartContainer
  config={chartConfig}
  className="w-full"
  height={250} // Fixed height
  initialDimension={{ width: 320, height: 200 }} // Loading state dimensions
  aspect={16 / 9} // Aspect ratio
  debounce={300} // Debounce resize events (ms)
  minHeight={200} // Minimum height
  maxHeight={600} // Maximum height
  onResize={(width, height) => {}} // Resize callback
  innerResponsiveContainerStyle={{}} // Additional container styles
>
  {/* Your Recharts components */}
</ChartContainer>
```

**Props:**

- `config` (required): `ChartConfig` - Chart configuration with colors, labels, and icons
- `className`: Custom CSS classes for the wrapper
- `height`, `width`: Fixed dimensions (number or string)
- `initialDimension`: Default dimensions during chart initialization
- `aspect`: Aspect ratio for responsive sizing
- `debounce`: Debounce time for resize events
- `minHeight`, `maxHeight`, `minWidth`: Dimension constraints
- `onResize`: Callback fired when chart resizes
- `innerResponsiveContainerStyle`: Styles for the inner ResponsiveContainer

### ChartTooltip & ChartTooltipContent

Custom tooltip components with built-in styling and theming. Uses Recharts v3 types.

**Basic Usage:**

```tsx
<ChartTooltip content={<ChartTooltipContent />} />
```

**With Advanced Options:**

```tsx
<ChartTooltip
  content={
    <ChartTooltipContent
      indicator="line" // 'dot' | 'line' | 'dashed'
      hideLabel={false} // Hide the label
      hideIndicator={false} // Hide the indicator
      labelFormatter={(value, payload) => `Custom: ${value}`}
      formatter={(value, name) => [`${value} units`, name]}
      nameKey="category" // Custom name key
      labelKey="date" // Custom label key
    />
  }
  cursor={false} // Hide cursor
  defaultIndex={0} // Initial active item (v3)
  active // Keep tooltip active (v3)
/>
```

**Type Reference:**

- Uses `ValueType` and `NameType` from `recharts/types/component/DefaultTooltipContent`
- Extends `DefaultTooltipContentProps` from Recharts v3

### ChartLegend & ChartLegendContent

Custom legend components with automatic color and label mapping. Uses Recharts v3 types.

**Basic Usage:**

```tsx
<ChartLegend content={<ChartLegendContent />} />
```

**With Advanced Options:**

```tsx
<ChartLegend
  content={
    <ChartLegendContent
      hideIcon={false} // Hide legend icons
      nameKey="category" // Custom name key for data mapping
      verticalAlign="top" // 'top' | 'bottom'
    />
  }
  verticalAlign="bottom"
  align="center"
/>
```

**Type Reference:**

- Uses `DefaultLegendContentProps` from Recharts v3
- Supports custom payload types with proper TypeScript inference

## Accessibility

All charts include accessibility features:

- Keyboard navigation support
- Screen reader friendly labels
- ARIA attributes
- High contrast color schemes

**Accessibility is enabled by default in Recharts v3.** The `accessibilityLayer` prop defaults to `true`.

```tsx
<AreaChart accessibilityLayer data={chartData}>
  {/* ... */}
</AreaChart>;

{
  /* To disable (not recommended): */
}
<AreaChart accessibilityLayer={false} data={chartData}>
  {/* ... */}
</AreaChart>;
```

## Best Practices

1. **Set appropriate dimensions** - Use `height` prop or `className` with Tailwind utilities:

   ```tsx
   {
     /* Option 1: Using height prop */
   }
   <ChartContainer config={config} height={250} className="w-full" />;

   {
     /* Option 2: Using Tailwind classes */
   }
   <ChartContainer config={config} className="max-h-[250px] min-h-[200px] w-full" />;
   ```

2. **Use initialDimension for loading states** - Prevents layout shift during chart initialization:

   ```tsx
   <ChartContainer config={config} initialDimension={{ width: 320, height: 200 }} />
   ```

3. **Optimize resize performance** - Use debounce for charts that resize frequently:

   ```tsx
   <ChartContainer config={config} debounce={300} />
   ```

4. **Use semantic data** - Provide meaningful labels and descriptions in your `ChartConfig`

5. **Keep it simple** - Don't overcrowd charts with too much data

6. **Test responsiveness** - Ensure charts work on all screen sizes using `minHeight`/`maxHeight`

7. **Consider color blindness** - Use patterns, textures, or icons in addition to colors

8. **Provide context** - Include titles, labels, and legends where appropriate

9. **Leverage TypeScript** - Use `satisfies ChartConfig` for type-safe configuration
