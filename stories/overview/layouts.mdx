# Layouts

A powerful collection of **14+ layout components** for building flexible and responsive user interfaces. These components provide a foundation for structuring your application with CSS Flexbox, CSS Grid, semantic HTML, and comprehensive Typography components.

## Installation

Install the required packages:

```bash
pnpm add @paalstack/react-ui @paalstack/react-icons @paalstack/react-hooks
```

For detailed setup instructions including Tailwind CSS v4 configuration, see the [Getting Started](/docs/overview-getting-started--docs) guide.

## Quick Start

```jsx
import { Box, Container, Flex, HStack, Stack, ThemeProvider, VStack } from '@paalstack/react-ui';

function MyApp() {
  return (
    <ThemeProvider>
      <Container className="px-4">
        <Stack className="gap-6">
          <HStack className="justify-between">
            <Box>Logo</Box>
            <Box>Navigation</Box>
          </HStack>
          <Flex className="items-center justify-between">
            <VStack>
              <Box>Title</Box>
              <Box>Description</Box>
            </VStack>
            <Box>Action</Box>
          </Flex>
        </Stack>
      </Container>
    </ThemeProvider>
  );
}
```

## Layout Components

### 📦 Box

The foundation of all layout components. A polymorphic component that can render as any HTML element.

**[View Documentation](/docs/layouts-box--docs)**

```jsx
import { Box } from '@paalstack/react-ui';

// Render as different elements
<Box as="section" className="p-4">Content</Box>
<Box as="article" className="bg-white rounded-lg">Article</Box>
<Box as="header" className="border-b">Header</Box>
```

**Key Features:**

- 🔄 Polymorphic - renders as any HTML element via `as` prop
- 🎨 Full Tailwind CSS support via `className`
- 🎯 Special style props: `bg`, `textColor`, `borderColor`, `fontSize`
- 📝 TypeScript support with proper element types
- ♿ Semantic HTML
- 📚 Comprehensive JSDoc examples in source code

**Special Props:**

- `bg` - Background color variant (gray, red, blue, green, yellow, etc.)
- `textColor` - Text color variant (primary, secondary, muted, etc.)
- `borderColor` - Border color variant
- `fontSize` - Font size variant (xs, sm, base, lg, xl, etc.)

### 🔲 Container

A responsive container that centers content and applies max-width constraints using Tailwind's `container` class.

**[View Documentation](/docs/layouts-container--docs)**

```jsx
import { Container } from '@paalstack/react-ui';

<Container className="px-4">
  <h1>Centered Content</h1>
  <p>This content is centered with max-width constraints</p>
</Container>;
```

**Key Features:**

- 📏 Uses Tailwind's responsive container breakpoints
- 📱 Responsive by default
- 🎯 Auto-centering with `mx-auto`
- 🔧 Add horizontal padding via `className` (e.g., `className="px-4"`)

### 🔀 Flex

Flexbox container for flexible layouts. A simple Box with `display: flex` applied.

**[View Documentation](/docs/layouts-flex--docs)**

```jsx
import { Flex } from '@paalstack/react-ui';

<Flex className="flex-row items-center justify-between gap-4">
  <Box>Item 1</Box>
  <Box>Item 2</Box>
  <Box>Item 3</Box>
</Flex>;
```

**Key Features:**

- 📦 Box component with `display: flex`
- ↔️ Direction control via Tailwind classes (`flex-row`, `flex-col`)
- 📍 Alignment via Tailwind classes (`items-center`, `justify-between`)
- 📏 Gap support via Tailwind classes (`gap-4`)
- 🔄 Wrap control via `flex-wrap`

### 📚 Stack

Vertical or horizontal stack layout with consistent spacing.

**[View Documentation](/docs/layouts-stack--docs)**

```jsx
import { Stack } from '@paalstack/react-ui';

<Stack className="gap-4">
  <Box>Item 1</Box>
  <Box>Item 2</Box>
  <Box>Item 3</Box>
</Stack>

<Stack direction="row" className="gap-4">
  <Box>Horizontal 1</Box>
  <Box>Horizontal 2</Box>
</Stack>
```

**Key Features:**

- 📐 Vertical layout by default (`flex-col`)
- 📏 Default gap of `gap-2` (0.5rem)
- ↔️ Optional `direction` prop ('row' | 'column')
- 🎯 Override gap via `className`

### 🌐 Grid

CSS Grid container for advanced grid layouts. Use Tailwind grid utilities for configuration.

**[View Documentation](/docs/layouts-grid--docs)**

```jsx
import { Grid } from '@paalstack/react-ui';

<Grid className="grid-cols-3 gap-4">
  <GridItem className="bg-gray-100 p-4">Item 1</GridItem>
  <GridItem className="bg-gray-100 p-4">Item 2</GridItem>
  <GridItem className="bg-gray-100 p-4">Item 3</GridItem>
  <GridItem className="bg-gray-100 p-4">Item 4</GridItem>
  <GridItem className="bg-gray-100 p-4">Item 5</GridItem>
  <GridItem className="bg-gray-100 p-4">Item 6</GridItem>

```

**Key Features:**

- 📊 Box with `display: grid`
- 🔢 Column and row control via Tailwind classes
- 📏 Gap support via `gap-*` utilities
- 📱 Responsive grid patterns (`grid-cols-1 md:grid-cols-3`)

**Common Tailwind Classes:**

- `grid-cols-{n}` - Number of columns
- `grid-rows-{n}` - Number of rows
- `gap-{size}` - Gap between items
- `col-span-{n}` - Column span for grid items

**Companion Component:**

- `GridItem` - Optional wrapper for grid items (just a Box)

**Companion Component:**

- `WrapItem` - Individual wrapper for flex items

### 📄 Paper

Card-like container with elevation (shadow) and optional border.

**[View Documentation](/docs/layouts-paper--docs)**

```jsx
import { Paper } from '@paalstack/react-ui';

<Paper shadow="md" withBorder className="p-6">
  <Heading>Card Title</Heading>
  <Text>Card content goes here</Text>
</Paper>;
```

**Key Features:**

- 🎴 Card-like appearance with background/foreground colors
- 🌑 Shadow variants (sm, md, lg, xl, 2xl, inner, none)
- 🖼️ Optional border via `withBorder` prop
- 🎨 No default padding - add via `className`

**Props:**

- `shadow` - Shadow size ('default' | 'sm' | 'md' | 'lg' | 'xl' | '2xl' | 'inner' | 'none')
- `withBorder` - Adds border (boolean)

### 🚪 Portal

Renders children into a DOM node outside the parent hierarchy using React's `createPortal`.

**[View Documentation](/docs/layouts-portal--docs)**

```jsx
import { Portal } from '@paalstack/react-ui';

// Renders to document.body by default
<Portal>
  <div className="fixed inset-0 bg-black/50">
    <div className="modal">Modal content</div>
  </div>
</Portal>

// Render to specific target
<Portal target="#modal-root">
  <div>Modal content</div>
</Portal>
```

**Key Features:**

- 🚪 Renders outside parent DOM hierarchy
- 🎯 Perfect for modals, tooltips, dropdowns
- 🔧 Custom target support via `target` prop (string selector or HTMLElement)
- ⚡ Auto-cleanup on unmount
- 🌐 SSR-safe with isomorphic effects

**Props:**

- `target` - Element or selector to render into (defaults to `document.body`)

**[View Documentation](/docs/layouts-heading--docs)**

**Key Features:**

- 📝 Semantic HTML (h1-h6) via `as` prop
- 📏 Automatic sizing based on heading level
- 🎨 Preset font weights (bold for h1-h2, semibold for h3-h6)
- ♿ Accessible heading hierarchy
- 📚 7+ usage examples in JSDoc

**Default Styles:**

- `h1` - `text-3xl font-bold`
- `h2` - `text-2xl font-bold`
- `h3` - `text-xl font-semibold`
- `h4` - `text-lg font-semibold`
- `h5` - `text-base font-semibold`
- `h6` - `text-sm font-semibold`

## Best Practices

### 1. Use Semantic HTML

Leverage the `as` prop for semantic markup:

```jsx
<Box as="main">Main content</Box>
<Box as="aside">Sidebar</Box>
<Box as="article">Blog post</Box>
```

### 2. Consistent Spacing

Use Tailwind's spacing scale consistently via `className`:

```jsx
<Stack className="gap-4">
  {' '}
  {/* 1rem = 16px */}
  <Box className="p-4">
    <VStack className="gap-2">
      {' '}
      {/* 0.5rem = 8px */}
      ...
    </VStack>
  </Box>
</Stack>
```

**Default Gaps:**

- `Stack`, `VStack`, `HStack`, `Wrap` - `gap-2` (0.5rem) by default
- Override via `className="gap-{size}"`

### 3. Responsive Design

Combine layout components with Tailwind responsive utilities:

```jsx
<Stack className="gap-4 md:flex-row">
  <Box className="w-full md:w-1/3">Sidebar</Box>
  <Box className="w-full md:w-2/3">Content</Box>
</Stack>
```

**Note:** Stack is `flex-col` by default, so you only need to add `md:flex-row` for responsive horizontal layout.

### 4. Composition Over Props

Compose components for complex layouts:

```jsx
<Container className="px-4">
  <Stack className="gap-8">
    <Paper className="p-6">
      <VStack className="gap-4">
        <Heading>Title</Heading>
        <Wrap className="gap-2">
          <Badge>Tag 1</Badge>
          <Badge>Tag 2</Badge>
        </Wrap>
      </VStack>
    </Paper>
  </Stack>
</Container>
```

## TypeScript Support

| -------------- | ------------------------- | --------------- | ----------- |
| **Box**        | Foundation component      | block           | -           |
| **Container**  | Responsive container      | block           | -           |
| **Flex**       | Flexbox container         | flex            | -           |
| **Grid**       | CSS Grid container        | grid            | -           |
| **Stack**      | Vertical/horizontal stack | flex (column)   | gap-2       |
| **VStack**     | Vertical stack            | flex (column)   | gap-2       |
| **HStack**     | Horizontal stack          | flex (row)      | gap-2       |
| **Wrap**       | Wrapping flex container   | flex (wrap)     | gap-2       |
| **Center**     | Center content            | flex            | -           |
| **Paper**      | Card-like container       | block           | -           |
| **Portal**     | Render outside hierarchy  | -               | -           |
| **Heading**    | Semantic headings         | block           | -           |
| **Text**       | Text/paragraph            | block/inline    | -           |
| **Typography** | 20+ text components       | varies          | -           |
