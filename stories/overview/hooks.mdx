# React Hooks

A comprehensive collection of **73 custom React hooks** designed to simplify common tasks and enhance your development workflow. These hooks cover state management, UI interactions, browser APIs, performance optimization, and more.

## Installation

```bash
pnpm add @paalstack/react-hooks
```

## Usage

Import the hooks you need from `@paalstack/react-hooks`:

```jsx
import { useCounter, useLocalStorage, useToggle } from '@paalstack/react-hooks';

function MyComponent() {
  const [isOpen, toggle] = useToggle();
  const [count, { increment, decrement }] = useCounter(0);
  const [value, setValue] = useLocalStorage('my-key', 'default');

  return (
    <div>
      <button onClick={toggle}>{isOpen ? 'Close' : 'Open'}</button>
      <button onClick={() => increment()}>Count: {count}</button>
      <input value={value} onChange={(e) => setValue(e.target.value)} />
    </div>
  );
}
```

### 🆕 New Hooks

Recently added hooks expanding the library's capabilities.

- **[useAsRef](/docs/hooks-state-management-useasref--documentation)** - Returns a stable ref synchronized with the latest value via `useIsomorphicEffect` (effect-phase write, SSR-safe). Prevents stale closures in event listeners and intervals without re-subscribing.
- **[useLazyRef](/docs/hooks-state-management-uselazyref--documentation)** - Returns a stable ref whose `.current` is lazily initialized by a factory function on the first render only — the factory never runs again. Ideal for expensive resources, class instances, and imperative stores.

## Common Patterns

### State Management Example

```jsx
import { useCounter, useInputState, useToggle } from '@paalstack/react-hooks';

function Counter() {
  const [count, { increment, decrement, reset, set }] = useCounter(0, { min: 0, max: 10 });
  const [enabled, toggle] = useToggle(true);
  const [name, setName] = useInputState('');

  return (
    <div>
      <input value={name} onChange={setName} placeholder="Enter name" />

      <button onClick={toggle}>{enabled ? 'Disable' : 'Enable'}</button>

      {enabled && (
        <>
          <h2>Count: {count}</h2>
          <button onClick={() => increment()}>+</button>
          <button onClick={() => decrement()}>-</button>
          <button onClick={() => reset()}>Reset</button>
        </>
      )}
    </div>
  );
}
```

function Settings() {

### UI Interactions Example

```jsx
import { useClickOutside, useHotkeys, useHover } from '@paalstack/react-hooks';

function Dropdown() {
  const [opened, { close, toggle }] = useDisclosure(false);
  const { hovered, ref: hoverRef } = useHover();
  const dropdownRef = useClickOutside(close);

  useHotkeys([
    ['Escape', close],
    ['mod+K', toggle],
  ]);

  return (
    <div>
      <button onClick={toggle}>Toggle Dropdown</button>
      {opened && (
        <div ref={dropdownRef}>
          <div ref={hoverRef} style={{ background: hovered ? 'blue' : 'gray' }}>
            Hover me
          </div>
        </div>
      )}
    </div>
  );
}
```

### Data Fetching Example

```jsx
import { useFetcher } from '@paalstack/react-hooks';

function UserProfile({ userId }) {
  const { data, loading, error, refetch } = useFetcher(`/api/users/${userId}`, { method: 'GET' });

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>{data?.name}</h1>
      <p>{data?.email}</p>
      <button onClick={refetch}>Refresh</button>
    </div>
  );
}
```

### Debouncing Example

```jsx
import { useDebouncedValue, useInputState } from '@paalstack/react-hooks';

function SearchBar() {
  const [search, setSearch] = useInputState('');
  const [debouncedSearch] = useDebouncedValue(search, 500);

  // debouncedSearch will only update 500ms after user stops typing
  useEffect(() => {
    if (debouncedSearch) {
      // Perform search API call
      searchAPI(debouncedSearch);
    }
  }, [debouncedSearch]);

  return <input value={search} onChange={setSearch} placeholder="Search..." />;
}
```

## Browser Compatibility

Most hooks work in all modern browsers. Some hooks require specific APIs:

- **useEyeDropper** - Requires EyeDropper API (Chromium-based browsers)
- **useFullscreen** - Requires Fullscreen API
- **useNetwork** - Requires Network Information API
- **useMediaQuery** - Requires matchMedia API

Always check browser compatibility for specific features at [caniuse.com](https://caniuse.com).

## Best Practices

### 1. **Cleanup and Memory Leaks**

Most hooks handle cleanup automatically, but be mindful of:

```jsx
// ✅ Good - hook handles cleanup
const { hovered } = useHover();

// ⚠️ Be careful with custom effects
useEffect(() => {
  const subscription = subscribe();
  return () => subscription.unsubscribe(); // Always cleanup
}, []);
```

### 2. **Dependencies**

Many hooks accept dependency arrays. Keep them accurate:

```jsx
// ✅ Good
useEventListener('click', handleClick, targetRef);

// ❌ Bad - missing dependencies could cause stale closures
useEffect(() => {
  doSomething(count);
}, []); // Should include 'count'
```

### 3. **Performance**

Use debouncing and throttling for expensive operations:

```jsx
// ✅ Good - debounced for performance
const [search] = useDebouncedValue(query, 300);

// ❌ Bad - triggers on every keystroke
useEffect(() => {
  expensiveSearch(query);
}, [query]);
```

### 4. **SSR Compatibility**

Use `useIsomorphicEffect` for SSR-safe effects:

```jsx
import { useIsomorphicEffect } from '@paalstack/react-hooks';

// Works in both browser and server
useIsomorphicEffect(() => {
  // This runs on both client and server safely
}, []);
```

### Stable Ref Patterns Example

```jsx
import { useAsRef, useLazyRef } from '@paalstack/react-hooks';

// useAsRef — stable ref always holding the latest callback, no re-subscription
function useWindowEvent(event, handler) {
  const handlerRef = useAsRef(handler);

  useEffect(() => {
    const listener = (e) => handlerRef.current(e);
    window.addEventListener(event, listener);
    return () => window.removeEventListener(event, listener);
  }, [event, handlerRef]); // handlerRef is stable — no teardown on handler change
}

// useLazyRef — create an expensive resource once, reuse across renders
function Chart({ data }) {
  const workerRef = useLazyRef(() => new Worker('/chart.worker.js'));

  useEffect(() => {
    workerRef.current.postMessage(data);
  }, [data, workerRef]);
}

// useLazyRef — hold an imperative store that outlives re-renders
function Counter() {
  const storeRef = useLazyRef(() => createCounterStore({ initialCount: 0 }));
  const [, forceUpdate] = useState(0);

  useEffect(() => storeRef.current.subscribe(() => forceUpdate((n) => n + 1)), [storeRef]);

  return (
    <div>
      <p>Count: {storeRef.current.get()}</p>
      <button onClick={() => storeRef.current.increment()}>+</button>
    </div>
  );
}
```
