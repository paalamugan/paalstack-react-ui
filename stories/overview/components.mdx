# Components

A comprehensive collection of **61+ accessible, customizable, and production-ready React components** built with Radix UI primitives and styled with Tailwind CSS v4. Each component is designed with best practices in mind, ensuring accessibility, responsiveness, and excellent developer experience.

## Installation

Install the required packages:

```bash
pnpm add @paalstack/react-ui @paalstack/react-icons @paalstack/react-hooks
```

For detailed setup instructions including Tailwind CSS v4 configuration, see the [Getting Started](/docs/overview-getting-started--docs) guide.

## Quick Start

```jsx
import { Alert, Button, Card, Input, Spinner, ThemeProvider } from '@paalstack/react-ui';

function MyApp() {
  const [isLoading, setIsLoading] = useState(false);

  return (
    <ThemeProvider>
      <Card>
        <Alert title="Welcome" description="Get started with our component library" />
        <Input placeholder="Enter your email" />
        <Button disabled={isLoading}>
          {isLoading && <Spinner size="sm" />}
          Submit
        </Button>
      </Card>
    </ThemeProvider>
  );
}
```

#### Native vs Radix UI Components

We provide two types of checkbox and radio components:

**Radix UI-based** (Checkbox, CheckboxGroup, RadioGroup):

- Built on Radix UI primitives
- Advanced features (indeterminate state, custom styling)
- Full accessibility with ARIA attributes
- Slightly larger bundle size
- Use for complex UIs requiring advanced features

**Native HTML-based** (NativeCheckbox, NativeCheckboxGroup, NativeRadio, NativeRadioGroup):

- Pure HTML input elements with custom styling
- Lightweight with minimal dependencies
- Native browser behavior
- Smaller bundle size
- Use for simple forms and lightweight applications

```jsx
// Radix UI-based (advanced features)
import { Checkbox, CheckboxGroup, RadioGroup } from '@paalstack/react-ui';

<Checkbox variant="primary" indeterminate />
<CheckboxGroup options={[...]} variant="success" />
<RadioGroup options={[...]} variant="primary" />

// Native HTML-based (lightweight)
import { NativeCheckbox, NativeCheckboxGroup, NativeRadio, NativeRadioGroup } from '@paalstack/react-ui';

<NativeCheckbox label="Accept terms" />
<NativeCheckboxGroup options={[...]} />
<NativeRadio label="Option 1" />
<NativeRadioGroup options={[...]} />
```

## Form Validation

Components integrate seamlessly with React Hook Form and Zod. Multiple approaches available:

### Field Component Approach

Use the Field component for granular control:

```jsx
import { zodResolver } from '@hookform/resolvers/zod';
import { Button, Field, FieldContent, FieldDescription, FieldError, FieldLabel, Input } from '@paalstack/react-ui';
import { useForm } from 'react-hook-form';
import { z } from 'zod';

const formSchema = z.object({
  username: z.string().min(2, 'Username must be at least 2 characters'),
  email: z.string().email('Invalid email address'),
});

function MyForm() {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm({
    resolver: zodResolver(formSchema),
  });

  return (
    <form onSubmit={handleSubmit((data) => console.log(data))}>
      <Field>
        <FieldLabel>Username</FieldLabel>
        <FieldContent>
          <Input {...register('username')} placeholder="Enter your username" />
          <FieldDescription>Choose a unique username</FieldDescription>
          <FieldError errors={[errors.username]} />
        </FieldContent>
      </Field>

      <Field>
        <FieldLabel>Email</FieldLabel>
        <FieldContent>
          <Input {...register('email')} type="email" placeholder="Enter your email" />
          <FieldError errors={[errors.email]} />
        </FieldContent>
      </Field>

      <Button type="submit">Submit</Button>
    </form>
  );
}
```

### Form Component Approach

Use the Form component for quick, declarative forms:

```jsx
import { zodResolver } from '@hookform/resolvers/zod';
import { Form } from '@paalstack/react-ui';
import { useForm } from 'react-hook-form';
import { z } from 'zod';

const formSchema = z.object({
  username: z.string().min(2),
  email: z.string().email(),
  role: z.string(),
  notifications: z.array(z.string()),
  contactMethod: z.string(),
  agreeToTerms: z.boolean(),
});

function MyForm() {
  const form = useForm({
    resolver: zodResolver(formSchema),
  });

  const fields = [
    {
      type: 'input',
      name: 'username',
      label: 'Username',
      placeholder: 'Enter your username',
      required: true,
    },
    {
      type: 'input',
      name: 'email',
      label: 'Email',
      placeholder: 'Enter your email',
      required: true,
    },
    {
      type: 'select',
      name: 'role',
      label: 'Role',
      placeholder: 'Select a role',
      options: [
        { value: 'admin', label: 'Admin' },
        { value: 'user', label: 'User' },
      ],
    },
    {
      type: 'native-checkbox-group',
      name: 'notifications',
      label: 'Notification Preferences',
      options: [
        { value: 'email', label: 'Email' },
        { value: 'sms', label: 'SMS' },
        { value: 'push', label: 'Push Notifications' },
      ],
    },
    {
      type: 'native-radio-group',
      name: 'contactMethod',
      label: 'Preferred Contact Method',
      options: [
        { value: 'email', label: 'Email' },
        { value: 'phone', label: 'Phone' },
      ],
    },
    {
      type: 'native-checkbox',
      name: 'agreeToTerms',
      label: 'I agree to the terms and conditions',
    },
  ];

  return <Form form={form} fields={fields} onSubmit={(data) => console.log(data)} submitText="Submit" />;
}
```

## Theming

All components support dark mode and custom themes through CSS variables:

### React Applications

```jsx
import { Button, ThemeProvider, useTheme } from '@paalstack/react-ui';

function App() {
  return (
    <ThemeProvider defaultTheme="system" storageKey="app-theme">
      <YourApp />
    </ThemeProvider>
  );
}

function ThemeToggle() {
  const { theme, setTheme, toggleTheme, isDark } = useTheme();

  return <Button onClick={toggleTheme}>Switch to {isDark ? 'Light' : 'Dark'} Mode</Button>;
}
```

### Next.js Applications

```jsx
import { Button, NextThemeProvider, useNextTheme } from '@paalstack/react-ui';

function RootLayout({ children }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <NextThemeProvider defaultTheme="system">{children}</NextThemeProvider>
      </body>
    </html>
  );
}

function ThemeToggle() {
  const { theme, setTheme, resolvedTheme } = useNextTheme();

  return <Button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>Current: {resolvedTheme}</Button>;
}
```

## New & Enhanced Components

### FileUpload - Accessible File Upload

A fully composable file upload component built on Radix UI primitives with drag-and-drop, multi-file
support, upload progress tracking, and custom validation. All sub-components are individually
addressable via `data-qa` attributes for automated testing.

```jsx
import {
  FileUpload,
  FileUploadClear,
  FileUploadDropzone,
  FileUploadItem,
  FileUploadItemDelete,
  FileUploadItemMetadata,
  FileUploadItemPreview,
  FileUploadItemProgress,
  FileUploadList,
  FileUploadTrigger,
} from '@paalstack/react-ui';

// Basic single-file upload with dropzone
<FileUpload
  accept={{ 'image/*': ['.png', '.jpg', '.jpeg', '.gif', '.webp'] }}
  maxFiles={1}
  maxSize={5 * 1024 * 1024}
  onUpload={async (files, { onProgress }) => {
    for (const file of files) {
      // Simulate chunked upload
      for (let progress = 0; progress <= 100; progress += 10) {
        await new Promise((r) => setTimeout(r, 100));
        onProgress(file, progress);
      }
    }
  }}
>
  <FileUploadDropzone>
    <FileUploadTrigger asChild>
      <Button variant="outline">Choose files or drag & drop</Button>
    </FileUploadTrigger>
  </FileUploadDropzone>

  <FileUploadList>
    <FileUploadItem>
      <FileUploadItemPreview />
      <FileUploadItemMetadata />
      <FileUploadItemProgress />
      <FileUploadItemDelete />
    </FileUploadItem>
  </FileUploadList>
</FileUpload>

// Multi-file upload with validation and clear-all button
<FileUpload
  multiple
  maxFiles={5}
  maxSize={10 * 1024 * 1024}
  accept={{ 'application/pdf': ['.pdf'], 'image/*': [] }}
  onFileValidate={(file) => {
    if (file.name.includes('forbidden')) return 'This file name is not allowed.';
    return null; // valid
  }}
>
  <FileUploadDropzone>
    <FileUploadTrigger asChild>
      <Button>Upload files (max 5)</Button>
    </FileUploadTrigger>
  </FileUploadDropzone>

  <FileUploadList>
    <FileUploadItem>
      <FileUploadItemPreview />
      <FileUploadItemMetadata />
      <FileUploadItemProgress variant="fill" />
      <FileUploadItemDelete />
    </FileUploadItem>
  </FileUploadList>

  <FileUploadClear asChild>
    <Button variant="ghost">Clear all</Button>
  </FileUploadClear>
</FileUpload>
```

**FileUpload Features:**

- `accept` - MIME types and extensions filter (same format as `react-dropzone`)
- `multiple` / `maxFiles` - Single or multi-file mode with optional file count cap
- `maxSize` - Maximum file size in bytes per file
- `onUpload` - Async callback with per-file progress reporting (`onProgress`, `onSuccess`, `onError`)
- `onFileValidate` - Synchronous custom validator; return a string message to reject a file
- `disabled` - Fully disable the dropzone and all controls
- `FileUploadItemProgress` - Accepts `variant="linear"` (default), `variant="circular"`, or `variant="fill"`
- All sub-components expose a `data-qa` attribute for automated testing

Convenient wrapper for multiple skeletons with automatic spacing:

```jsx
import { SkeletonContainer } from '@paalstack/react-ui';

// Multiple lines (default spacing)
<SkeletonContainer count={3} />

// Circle skeletons for avatars
<SkeletonContainer circle count={5} className="h-12 w-12" />

// Custom spacing
<SkeletonContainer count={5} wrapperClassName="space-y-4" />

// Full width paragraphs

// User profile skeleton
<div className="flex items-start space-x-4">
  <SkeletonContainer circle className="h-16 w-16" />
  <div className="flex-1">
    <SkeletonContainer count={2} className="h-5" />
  </div>
</div>

// List of items
<div>
  {Array.from({ length: 3 }).map((_, i) => (
    <div key={i} className="flex items-center space-x-3 p-4 border-b">
      <SkeletonContainer circle className="h-10 w-10" />
      <div className="flex-1">
        <SkeletonContainer count={2} className="h-4" />
      </div>
    </div>
  ))}
</div>

// Blog post skeleton
<article className="space-y-4">
  <SkeletonContainer className="h-48 w-full rounded-lg" />
  <SkeletonContainer className="h-8 w-3/4" />
  <div className="flex items-center space-x-4">
    <SkeletonContainer circle className="h-8 w-8" />
    <SkeletonContainer count={2} className="h-3 w-24" />
  </div>
  <SkeletonContainer count={6} wrapperClassName="space-y-2" />
</article>
```

**SkeletonContainer Features:**

- `count` - Number of skeleton items to render
- `circle` - Render circular skeletons (perfect for avatars)
- `className` - Custom styles for each skeleton item
- `wrapperClassName` - Custom spacing and styles for the container
- `isFullWidth` - Make all items full width (disables auto-width for last item)
- Automatic width adjustment: Last item is 10/12 width by default for natural text ending

```jsx
    title: "User Profile",
    description: "Manage your account settings"
  }}
  footer={<Button>Save Changes</Button>}
>
  <Input placeholder="Name" />
  <Input type="email" placeholder="Email" />
</Card>
```

### 2. Controlled vs Uncontrolled

Most form components support both patterns:

```jsx
// Uncontrolled
<Input defaultValue="Hello" />;

// Controlled
const [value, setValue] = useState('');
<Input value={value} onChange={(e) => setValue(e.target.value)} />;
```

### 3. Responsive Design

Use Tailwind responsive classes:

```jsx
<Button className="w-full md:w-auto">Responsive Button</Button>
```

### 4. Loading States

Show loading indicators during async operations:

```jsx
// Button has built-in loading state
<Button isLoading={isLoading} loadingText="Submitting...">
  Submit
</Button>

// Or use Spinner component
import { Spinner } from '@paalstack/react-ui';

<Button disabled={isLoading}>
  {isLoading ? <Spinner size="sm" /> : null}
  {isLoading ? 'Loading...' : 'Submit'}
</Button>

// Spinner with different sizes
<Spinner size="xs" />
<Spinner size="sm" />
<Spinner size="md" />
<Spinner size="lg" />
<Spinner size="xl" />

// Spinner in badges
<Badge>
  <Spinner size="xs" />
  Syncing
</Badge>

// Or use Loading component separately
<Button disabled={isLoading}>
  {isLoading ? <Loading /> : 'Submit'}
</Button>
```
